## 지도와 좌표계

```json
{
  "mapName": "R_KR_PR_K-city_2025",
  "eastOffset": 302595.0,
  "northOffset": 4124145.0,
  "globalCoordinateSystem": "UTM52N",
  "scenarioCoordinateSystem": "ENU"
}
```

이 값은 MGeo `global_info.json`의 UTM Zone 52/WGS84 설정과 일치합니다.
따라서 MGeo와 시나리오가 서로 다른 지도라고 볼 근거는 현재 없습니다.

## Ego 차량 시작 상태

Ego 차량은 `initPositionMode=Absolute`입니다.

| 항목 | 값 |
|---|---:|
| 위치 | `(-131.485992, -427.960999, 28.883000)` |
| yaw | `62.515°` |
| 초기 속도 | 거의 `0` |
| 초기 기어 | `1` |
| 시작 link | 비어 있음 |
| 현재 제어 모드 | `1` |

대회 경로 첫 점은
`(-131.689798, -428.331023, 28.543960)`입니다.

- XY 거리: 약 `0.422 m`
- 첫 경로 구간 yaw: 약 `61.298°`
- Ego와 경로 방향 차이: 약 `1.217°`

이 샘플은 차량을 경로 시작점에 맞춰 둔 상태를 검증하기에 좋습니다.
다만 Ego의 z 값은 경로 z보다 약 `0.339 m` 높으므로, 차량 기준점과 도로
중심선의 높이 차이일 가능성이 있습니다. 제어용 XY 좌표와 고도 기준을
분리해서 다루는 것이 안전합니다.

## NPC 차량

NPC 차량은 9대이고 차량 모델 타입은 모두 JSON상 `257`입니다. 현재 속도와
목표 속도는 대략 20, 40, 50, 60 단위로 설정되어 있습니다. 이 단위가
km/h인지 MORAI 내부 단위인지는 공식 enum/문서로 확인해야 하므로 코드에서
임의로 환산하지 않습니다.

차량은 주로 다음 spawn point에서 생성됩니다.

- ID 10: 목표 속도 60, 생성 주기 10초
- ID 6: 목표 속도 40, 생성 주기 10초
- ID 8: 목표 속도 50, 생성 주기 10초
- ID 4: 목표 속도 20, 생성 주기 5초

이 시나리오는 단순 빈 트랙이 아니라, 여러 속도의 주변 차량이 계속
생성되는 교통 상황 테스트로 볼 수 있습니다.

## 보행자와 장애물

- 보행자 ID 3: 위치 `(-56.744, -11.614, 28.561)`, yaw `-83.262°`,
  속도 `10.0`, 활성화 상태
- 장애물 ID 2: 위치 `(-60.610, -142.178, 28.374)`, 크기 약 `(2,3,2)`,
  객체 타입 코드 `4`
- `PedPath - 3`: 보행자 waypoint 2개
- `ObstaclePath - 2`: waypoint 없음

따라서 Detection 팀은 카메라·LiDAR가 주변 차량뿐 아니라 정적 장애물과
보행자를 구분할 수 있는지 별도 시험해야 합니다.

## 교통신호와 V2I

- 교통신호 항목은 16개입니다.
- 상태 코드는 `0`, `2`, `3`이 사용됩니다.
- 상태 숫자의 정확한 의미는 MORAI 공식 enum을 확인하기 전까지 코드에서
  빨강·노랑·초록으로 직접 가정하지 않습니다.
- 상태 갱신 시간은 대부분 약 `7.044초`로 기록되어 있습니다.
- V2I는 `isAlive=false`, 수신 주소 `127.0.0.1:5000`입니다.

따라서 초기 Detection은 카메라 영상 기반 신호 인식과 시나리오 JSON의
정답 상태를 혼동하지 않아야 합니다. 시나리오의 신호 값은 테스트 기준
또는 정답 비교용이고, 실제 자율주행 판단은 센서 인식 결과를 사용해야
합니다.

## 이 파일의 활용 방법

1. Localization 팀: Ego 시작 위치·yaw와 경로 첫 점의 일치 검증
2. Control 팀: 경로 시작 link와 절대좌표 정책 검증
3. Detection 팀: NPC·보행자·장애물·신호 상황별 센서 시험 구성
4. 통합 시험: V2I가 꺼진 상태에서 카메라·LiDAR만으로 안전정지 가능한지
   확인

시나리오 JSON을 localization 결과나 detection 결과로 직접 사용하지
않습니다. 이는 MORAI 초기 상태를 설정하는 입력 파일입니다.
