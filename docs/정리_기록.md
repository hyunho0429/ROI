# 작업폴더 정리 기록

2026-08-09 기준으로 새 기준 저장소 morai_ws를 만들고, 지도·경로·센서·규정
자료와 팀 간 좌표계·토픽 계약을 이 폴더에 모았다.

## 보존한 것

- 대회 경로 원본
- 대회 참고 이미지와 시나리오
- 카메라 설정 원본
- MGeo 원본
- 세부 규정집
- ROS 토픽·메시지·좌표계 분석
- UDP fallback 포트 계약
- 새 팀별 폴더 구조

## 이번에 추가한 기준

- MORAI ROS 네이티브 입력 topic과 메시지 타입
- GPSMessage·sensor_msgs/Imu 기반 localization 입력
- EgoVehicleStatus 기반 GPS 정렬 검증
- sensor_msgs/CompressedImage 기반 카메라 4대 입력
- sensor_msgs/PointCloud2 기반 LiDAR 입력
- morai_msgs/CtrlCmd 기반 control 출력

## 레거시 실행 코드 상태

기존 ros_ws*, run+camera, running 등의 레거시 실행 폴더는 정리 대상으로
표시했지만, 현재 작업 중인 파일과 변경사항을 보호하기 위해 아직 실제 삭제하지
않았다. 삭제가 필요하면 대상 폴더와 보존할 변경사항을 먼저 확인한 뒤 별도
승인을 받고 처리한다.

새 코드는 과거 파일을 직접 복사하지 말고 인터페이스 계약에 맞춰 작성한다.
