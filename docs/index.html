청룡열차

경로 계획, 객체 인식, 위치 추정, 제어 입력을 한 흐름으로 묶어 시뮬레이터에서 바로 실험할 수 있는 자율주행 모듈 홈페이지입니다.

Mode Autonomous
Path K-City
Control Pure Pursuit

Drive Stack

센서에서 조향까지 이어지는 실행 흐름

01

Localization

현재 위치와 전역 경로를 기준으로 로컬 경로를 구성합니다.

02

Perception

주행 경로 앞의 객체를 분류하고 추종 대상 여부를 판단합니다.

03

Planning

Adaptive Cruise Control 로직으로 목표 속도를 계산합니다.

04

Control

PID와 Pure Pursuit로 가감속과 조향 입력을 생성합니다.
