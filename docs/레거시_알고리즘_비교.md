# 기존 경로추종 알고리즘 비교 기록

이 문서는 삭제된 예전 실행 코드의 비교 기준만 보존한 것입니다. 새 제어
코드는 이 문서의 패키지를 복원하는 방식이 아니라, `morai_ws/src/control`
내의 새 인터페이스에 맞춰 작성합니다.

## 비교 대상

| 예전 이름 | 방식 | 주요 특성 |
|---|---|---|
| `ros_ws` | Pure Pursuit | 기본 경로추종 |
| `ros_ws2` | Adaptive Pure Pursuit | 속도·곡률에 따른 lookahead 조정 |
| `ros_ws3` | Stanley | heading error와 횡방향 오차 보정 |
| `ros_ws4` | Hybrid | Pure Pursuit와 Stanley 혼합 |

## 비교 조건

알고리즘 비교 시 MORAI 지도, 차량, 시작 위치, 경로, 날씨, 교통, 센서,
목표 속도를 모두 같게 유지합니다. 서로 다른 경로 파일을 사용하면
알고리즘 비교가 아닙니다.

확인할 항목은 직선 구간의 좌우 흔들림, 곡선 진입·탈출, 최초 방향 오류,
최대 횡방향 오차, 마지막 정지 여부입니다.

## 문제 해석 순서

- 모든 알고리즘이 흔들리면 제어 게인보다 좌표계, yaw, steering 부호,
  waypoint 간격, GPS 안정성을 먼저 확인합니다.
- Stanley만 흔들리면 Stanley gain과 저속 softening을 확인합니다.
- Pure Pursuit가 늦게 돌면 lookahead를 줄이고, 안쪽을 과도하게 자르면
  lookahead를 늘립니다.
- Hybrid가 Stanley처럼 흔들리면 Stanley 가중치를 줄입니다.

새 구조에서 알고리즘의 성공 여부는 [실험기록.md](실험기록.md)에 기록하고,
한 번의 시험에서 여러 파라미터를 동시에 바꾸지 않습니다.
