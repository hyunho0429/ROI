# 대회 자료 정리

## 저장 위치

| 원본 자료 | 새 저장 위치 | 용도 |
|---|---|---|
| `global_info.json` | `data/mgeo/R_KR_PR_K-city_2025/` | MGeo 좌표계·원점·버전 |
| `link_set.json` | `data/mgeo/R_KR_PR_K-city_2025/` | 도로·차선 link geometry |
| `node_set.json` | `data/mgeo/R_KR_PR_K-city_2025/` | link 연결 node |
| `cam_set.json` | `data/sensors/` | 카메라 위치·화각·해상도 원본 |
| 샘플 시나리오 | `data/scenarios/` | Ego·NPC·보행자·신호 초기상태 |
| 대회 경로 | `data/routes/` | 기준 주행 경로 |
| 세부 규정집 | `data/regulations/세부규정집2026.pdf` | 대회 운영·센서·네트워크·채점 기준 |

## 현재 확인된 사실

- MGeo와 대회 경로의 좌표점이 일치합니다.
- 샘플 시나리오는 MGeo와 같은 K-City 2025 지도와 UTM52N/ENU를 사용합니다.
- 샘플 Ego는 대회 경로 첫 점과 약 0.422 m 차이로 배치되어 있습니다.
- `cam_set.json`은 카메라 3개 설정만 포함합니다.
- GPS·IMU·LiDAR는 `cam_set.json`에서 설정되지 않았습니다.
- 카메라 원본 JSON의 UDP 포트와 최종 알고리즘 포트는 다르므로,
  `config/sensor_ports.yaml`의 최종 포트 계약을 사용해야 합니다.
- 규정집의 지도 표기와 JSON의 지도 표기에 차이가 있으므로, 실제 현장
  지도 버전을 반드시 운영측과 확인해야 합니다.
