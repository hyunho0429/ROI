# 대회 경로 사용 기준

대회 경로는 공백으로 구분된 `x y z` 형식입니다. 현재 파일은
`morai_ws/data/routes/2026_molit_comp_global_path.txt`입니다.

경로 좌표는 지도 형태의 미터 단위 좌표이고, 현재 GPS localizer의 최초
원점 `(0,0)`과 직접 같은 좌표계라고 가정하면 안 됩니다.

## 시작 정책

- 첫 실행은 경로의 waypoint 0부터 시작합니다.
- MGeo와 GPS의 좌표계가 같다는 것이 확인되기 전에는 경로를 임의로
  회전하지 않습니다.
- 경로를 차량 위치에 맞추는 변환은 한 번만 수행하며, 팀 공통 설정으로
  관리합니다.
- ROS CtrlCmd는 MORAI 차량을 순간이동하거나 회전시키지 못합니다.

## 최초 검증

1. 차량을 MORAI에서 대회 경로의 시작 위치에 배치합니다.
2. GPS와 IMU의 초기 자세를 확인합니다.
3. 경로와 차량의 시작점·진행방향을 그림으로 확인합니다.
4. 3 m/s 이하의 저속에서 경로 index와 상태 추정을 확인합니다.
5. 위치·자세·경로 좌표가 일치한 뒤에만 제어 파라미터를 조정합니다.
