### 🚨 실행 전 주의사항 (Prerequisites)

* 커스텀 사물 인식 모델을 실행하기 위해 **`null.pt`** (가중치 파일)가 반드시 필요합니다.
* 깃허브 용량 제한으로 해당 파일은 레포지토리에 업로드되지 않았습니다.
* **파일 위치:** 연구실 PC의 `moris_ws/src/detection/` 폴더 내에 저장되어 있습니다.
* **적용 방법:** 해당 파일을 복사하여 이 프로젝트의 `Sensor/` 폴더 안에 넣고 코드를 실행해 주세요. (또는 `YoloCamera_v1.py` 코드 내의 `CUSTOM_MODEL_PATH` 경로를 직접 수정하셔도 됩니다.)
* *(참고: 기본 모델인 `yolov8n.pt`는 로컬에 파일이 없어도 코드 실행 시 자동으로 다운로드됩니다.)*
